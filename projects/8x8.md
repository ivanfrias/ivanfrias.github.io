# 8x8 / Fuze projects

_Following 8x8's acquisition of Fuze in 2022, engineering solutions and services evolved to support global UCaaS/CCaaS enterprise customers as Senior Software Engineer._

## _Bulk sound upload utility_

**Type**: customer-facing

**Architecture**: command-line utility

**Description**: Developed a command-line bulk upload tool, used by a large customer to upload call-flow related audio-files on a regular basis.

**Technologies**: Node.js, Mocha, Chai, TypeScript, REST

## _Number Portability & Carrier Integration_

**Type**: customer & internal facing

**Architecture**: full-stack

**Description**: Full-stack developer on an internal project (front-end and back-end) that automates number request and number porting from losing carriers. Front-end is a React web application integrated into the customer provisioning portal. Back-end is a microservice acting as an integration hub between homegrown APIs and third-party telecom carriers. Focus included redesigning the backend to increase code quality through unit and integration testing while delivering new features on top of existing services.

**Technologies**: React, TypeScript, JavaScript, HTML, CSS, Java 8/11, Spring Boot, Docker, JUnit 4/5, TestNG, Mockito, PostgreSQL, Liquibase, MyBatis

## _Contact Rosters Hub_

**Type**: customer & internal facing

**Architecture**: front-end

**Description**: Worked as a front-end developer on an initiative to implement from scratch a back-office feature allowing enterprise customers to configure contact groups, visibility rules across groups, and manage associated peers.

**Technologies**: React, TypeScript, JavaScript, HTML, CSS, REST, Selenium, Mocha

## _Bulk Provisioning Utility_

**Type**: internal facing

**Architecture**: desktop application

**Description**: Developed a bulk provisioning desktop application used by internal services & support teams. Enables users to upload CSV cutsheets with user/device metadata to visualize changes (add, modify, delete) and execute provisioning workflows, cutting onboarding turnaround time from hours to seconds.

**Technologies**: Vue.js, Vuex, Vuetify, HTML, CSS, Electron, Node.js, CouchDB, REST

## _Email2Fax Service_

**Type**: customer facing

**Architecture**: serverless microservice

**Description**: Developed a serverless microservice that parses email content (subject, body, attachments) and sends faxes using proprietary cloud APIs.

**Technologies**: Node.js, JavaScript, AWS Lambda, AWS SNS, AWS S3, REST

## _Customized Click-to-Call Browser Extension & Backend_

**Type**: customer & internal facing

**Architecture**: full-stack (browser extension, web back-office, microservice)

**Description**: Customized a browser extension enabling users to place calls by masking outbound numbers. Developed a supporting microservice and back-office web application to configure and query masked numbers.

**Technologies**: Vue.js, JavaScript, HTML, CSS, REST, AWS S3, Bootstrap, AWS Route 53, AWS EC2

## _SIP Peers Lookup Web Application_

**Type**: internal facing

**Architecture**: full-stack

**Description**: Scoped, designed, and implemented an internal web application allowing teams to search, filter, and inspect sensitive SIP peer configuration data through a dedicated query microservice.

**Technologies**: Vue.js, JavaScript, HTML, CSS, REST, Express.js, AWS EC2, AWS Route 53

## _Fuze Connect Provisioning Tool_

**Type**: internal facing

**Architecture**: full-stack

**Description**: Built a back-office tool to manage configurations and provision users for Fuze Connect, powered by a Vue.js web client and an Express.js microservice.

**Technologies**: Vue.js, JavaScript, HTML, CSS, REST, Express.js, MySQL, AWS EC2, AWS Route 53
